Hallo, wereld.

Dit is de kleinste app die er bestaat: een pagina die iets zegt. Het bijzondere is niet wát er staat, maar hoe het er kwam — door te beschrijven wat je wilde, in gewone taal. Dat is vibecoden.

Wat je hier eigenlijk ziet

Eén bestand, drie talen die samenwerken.

HTML
De woorden en de structuur. Dit is een kop, dit is een knop, dit is een invulveld. Het skelet.
CSS
Het uiterlijk. Kleuren, lettertypes, ruimte tussen dingen. Iedere sfeer hierboven is niets anders dan een setje andere CSS-regels.
JavaScript
Het gedrag. Als je op feest klikt, is het JavaScript dat luistert en de sfeer omzet.

Vibecoden in drie stappen

  1. Je beschrijft in gewone taal wat je wil hebben.
  2. De computer schrijft de code en zet de bestanden neer.
  3. Jij kijkt of het klopt en vraagt om wat er nog mist.

Stap drie is de echte. Vibecoden gaat niet over code uit handen geven, maar over sneller bij de vraag komen die ertoe doet: klopt dit, en wil ik dit zo?
